# x360 LED Fix v2

Приложение для Android TV (Google TV), которое отправляет геймпаду Xbox 360
(через оригинальный беспроводной ресивер 045E:0719) LED-команду, из-за которой
перестаёт мигать кольцо из четырёх индикаторов.

## Что изменилось во второй версии

- **Исправлен формат пакета.** LED-команда для беспроводного ресивера в драйвере
  xpad ядра Linux — это 12 байт: `00 00 08 (0x40 + код) 00…00`, первый байт 0x00.
  В первой версии посылался пакет с первым байтом 0x01, который ресивер
  игнорировал. Теперь отправляются оба варианта (0x00 — основной, 0x01 — запасной).
- **Подробный журнал.** Приложение показывает: какие интерфейсы ресивера удалось
  захватить, адрес OUT-эндпоинта и сколько байт реально записано по каждому
  варианту пакета.
- **Кнопка «Список USB-устройств»** — показывает, как ресивер видит система.

## Коды LED

- 0 — погасить все индикаторы;
- 6..9 — стабильно гореть как игрок 1..4.

Состояние индикаторов хранится в самом геймпаде — команда нужна один раз
после каждого включения геймпада.

## Сборка APK через GitHub Actions

1. Создайте новый репозиторий на GitHub (Public).
2. Загрузите в него все файлы и папки этого архива (содержимое, не сам zip).
3. Вкладка **Actions** → при необходимости включите workflows кнопкой
   «I understand my workflows…» → выберите **Build APK** → **Run workflow**.
4. Через 5–10 минут скачайте артефакт `x360ledfix-debug-apk`.

## Установка на телевизор

1. Скопируйте APK на флешку.
2. Установите через файловый менеджер (разрешив «неизвестные источники»).
3. Вставьте ресивер в USB-порт телевизора, включите геймпад.
4. Запустите приложение и нажмите «ПОГАСИТЬ ИНДИКАТОРЫ».
   В журнале смотрите строки «стандарт=X байт, XBE2=Y байт».

## Важно

- После захвата интерфейсов ядро может не вернуть драйвер: если кнопки геймпада
  перестанут доходить до телевизора — выньте и снова вставьте ресивер.
  LED-состояние геймпада при этом сохранится.
- Галочка «Повторять» нужна, чтобы команда ставилась заново после включения
  геймпада (LED-состояние сбрасывается при его выключении).
